# TECHHUB – Activity 2 

This starter project applies:
- **Access control:** login checks, active/blocked status checks, admin/user route protection.
- **User management:** admin can add, view, edit, block/activate, and delete users.
- **Product CRUD:** admin can create, read, update, and delete products.
- Regular users can view the product catalog but cannot access admin pages.


 Sign out and sign in again. You should be redirected to the admin dashboard.

Public registration always creates a regular `user` account. Only an administrator can assign admin privileges.

##  Pages
- `signin.php` – sign in
- `register.php` – register
- `admin/dashboard.php` – admin dashboard
- `admin/users.php` – user management
- `admin/products.php` – product management
- `user/dashboard.php` – user dashboard
- `user/products.php` – view products

## Important
This is a clean starter implementation based on the `users` and `products` table structure. Back up your Activity 1 database before combining it with your existing TECHHUB project. Do not import the SQL over an existing database without checking the table structures first. Preserve your existing design by copying the PHP logic into your current pages and keeping your CSS where needed.
